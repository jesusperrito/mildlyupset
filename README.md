# mildlyupset

Content studio landing page — mildlyupset by Serviceplan.

## Structure

```
mildlyupset/
├── index.html
└── videos/
    └── MILDLY_UPSET_AI_REEL_1_1.mp4   ← place video file here
```

## Setup

1. Drop `MILDLY_UPSET_AI_REEL_1_1.mp4` into the `videos/` folder
2. Push to GitHub
3. Enable GitHub Pages: Settings → Pages → Deploy from branch → main → / (root)

Live at: https://YOUR_USERNAME.github.io/mildlyupset/
